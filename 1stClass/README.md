# 1stClass: Turma do Cocoricó

Primeira aula de Flutter: uma lista de personagens do Cocoricó em cards, com avatar carregado da internet (`Image.network`) e um ícone no lugar quando a imagem falha.

Tudo fica em `lib/main.dart`: a classe `Character`, a lista constante de personagens e um `ListView.separated`.

```bash
flutter pub get
flutter test
flutter run   # ou: flutter run -d chrome
```
